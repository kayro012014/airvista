#  AirVista

AirVista is a web-based flight booking system built as a school project. Users can book plane tickets, see the total fare before paying, and track their flight's departure and arrival times, just like a typical airline booking system.

##  Features

- **Ticket Booking** – Browse available flights and book a seat
- **Fare Summary** – See the total amount to pay before confirming
- **Flight Tracking** – Check departure and estimated arrival times
- **Booking Records** – View your booked flights in one place
